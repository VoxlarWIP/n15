Pipeline

Five-stage reverse compiler

Luraph V15 compiles scripts into a custom virtual machine with encrypted constants, flattened control flow, and active anti-tamper traps. This engine reverses each layer.

Stage 01
AST Analysis & Hooking
Parses the protected script with a Luau AST parser. Maps VM dispatcher loops and closure constructors. Injects non-destructive telemetry hooks to track proto execution and register states without altering behavior.
vmmap.js
Stage 02
Sandboxed Simulation
Executes the hooked script inside an offline Roblox engine emulator. If execution hits an anti-tamper trap (LPH_CRASH), the engine identifies the function, disables that trap path, and re-runs along stable branches.
driver.js · harness.js · envlog.luau
Stage 03
Live REPL Decryption
Luraph's lazy encryption requires dynamic keys only available at runtime. The engine queries a live Luau REPL process via IPC to decrypt thousands of string and numeric constants on-the-fly. Resolves 2,000–2,600 constants per pass.
devirt.js · luasym.py
Stage 04
CFG Reconstruction
Uses Sparse Conditional Constant Propagation (SCCP) to trace virtual register values. Assembles basic blocks into a directed control flow graph. Dominator tree analysis restores nested loops and branching logic. Prunes dead blocks from opaque predicates.
structure.py · loops.py
Stage 05
Register Web Analysis
Maps virtual registers across basic block boundaries using Static Single Assignment (SSA) web analysis. Assigns context-aware variable names inferred from Roblox API usage (Players, TweenService, ReplicatedStorage, etc.).
variables.py · codegen.py
Stage 06
Polish & Formatting
Converts function assignments into idiomatic Luau syntax. Formats with proper indentation. Verifies output through a compile check to guarantee 100% executable syntax. Fast-path controller skips redundant passes once all constants are resolved.
backend.py · tidy.js
Privacy

Your scripts stay in your network

NO-V15Today is a web interface that calls the deobfuscator engine running on your own server or machine. Scripts are processed locally and never transmitted to third-party services.

Self-hosted engine
The deobfuscation engine runs on a machine you control. No cloud backend, no upload API, no analytics.
Temporary files only
Input scripts are written to /tmp, processed, and deleted. No persistent storage.
No telemetry
This interface contains no analytics libraries, trackers, or beacons. What you paste stays between you and your server.

Setup

Get started in four steps

01
Clone the deobfuscator engine
The actual deobfuscation logic lives in the original repository. Clone it and install (it has no npm dependencies, but the clone brings the Luau binaries).
git clone https://github.com/caomod2077/Deobfuscator-Luraph-V15.git
02
Install this website's server dependencies
In the NO-V15Today directory, install the Express server dependencies so the web interface can communicate with the engine.
cd no-v15today npm install
03
Configure the engine path and start the server
Point the server at the cloned engine repo, then start. Requires Node.js 18+ and Python 3.10+.
export DEOBF_PATH=/path/to/Deobfuscator-Luraph-V15 node server.js
04
Open the interface
Open http://localhost:3000 in your browser. Upload or paste a Luraph V15-protected script and click Deobfuscate.

For Vercel deployment (detection mode + frontend only):

npm run build vercel --prod

When deployed to Vercel, the interface is fully functional but deobfuscation requires a self-hosted backend. Configure the backend URL in the app's Settings panel (⚙ icon, top right).
